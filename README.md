# Модуль "Примитивная база данных"

Простая база данных для работы с таблицами
Схемы таблиц хранятся в db_meta.json, а записи каждой таблицы в
data/<имя_таблицы>.json.

## Установка и запуск

Для запуска нужен Python 3.12 или новее и uv. Нужно выполнить:

```bash
uv sync
uv run database
```

## Основные операции

- `create_table <имя_таблицы> <название_колонки>:<тип>` - создание таблицы. Столбец ID создается автоматически;
- `list_tables` - вывод всех имен таблиц;
- `drop_table <имя_таблицы>` - удаление таблицы;
- `help` - помощь;
- `exit` - выход из программы.

## CRUD-операции

- `insert into <имя_таблицы> values (<значения>)` - добавление записи. ID создается автоматически;
- `select from <имя_таблицы>` - вывод всех записей таблицы;
- `select from <имя_таблицы> where <столбец> = <значение>` - вывод записей по условию;
- `update <имя_таблицы> set <столбец> = <новое_значение> where <условие>` - обновление записей по условию;
- `delete from <имя_таблицы> where <условие>` - удаление записей по условию;
- `info <имя_таблицы>` - вывод столбцов и количества записей.

Значения в values нужно указывать в порядке столбцов без ID. Строки пишутся
в кавычках, целые числа, true и false без кавычек.
Пример условия where age = 28. Команды update и delete работают со всеми
записями, которые подходят под условие.
